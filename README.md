# Python Forge — 180 Days of Building

I'm learning Python from the ground up by building something small, real, and slightly broken every single day. This repo is the public log of that journey.

**Rules I'm following:**
- Learn a little → build a little, every day
- Every project gets *broken on purpose* before I call it done — I try to make it crash so I understand *why* it works when it doesn't crash
- No skipping the messy parts

## How to run any day's code

Each day folder has its own script. Just run it with Python:

```bash
python3 day-01/analyzer.py
```
